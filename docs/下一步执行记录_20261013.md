## 推理诊断与当前停止点

已对训练集 seed 0、1、2 的每个非重叠 chunk，用该 chunk 开头的真实观测做开环预测。逐维 MSE（前六维 rad²，末维 m²）：

`[0.0002471, 0.0038437, 0.0036990, 0.0042430, 4.494e-9, 0.0186946, 0.00007539]`

输出：`logs/开环误差.json`、`logs/openloop_seed_{0,1,2}.npz`；复现脚本：`scripts/diagnose_smolvla_openloop_rebot.py`。这是训练集开环诊断，不代表闭环成功率。

发现两个问题：

1. 夹爪预测为 [-0.02345, 0.06162] m，35.93% 超出 [0, 0.05] m；joint6 最大 3.42882 rad，1.27% 越界。按 B0 手册动作范围验收规则，停止在闭环 SmolVLA rollout 前；没有启动 n=1 或 n=5 的 SmolVLA 闭环评测，也没有把该模型用于 B0 判定。
2. 保存的 state 特征元数据继承了 base 的 6 维，实际数据和保存的 state 统计量都是 7 维；action 元数据正确为 7 维。已准备 `configs/smolvla_rebot_input_features_v0.json`，正式训练时显式指定 state=7，其余输入配置继承本次模型；已验证 LeRobot 配置解析通过，未修改已有 checkpoint。

反归一化核查通过：保存的 action/state mean、std 与正式数据集一致；实际执行 postprocessor 时，零输入返回 action mean，单位输入返回 mean+std。因此目前没有证据表明越界由跳过反归一化导致；300 步模型的预测仍有误差，不能据此承诺正式训练后的效果。证据：`logs/next_step/inference_gate.json`。
