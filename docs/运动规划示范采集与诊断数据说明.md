# 运动规划示范采集与诊断数据说明（ReBot B601-DM，ManiSkill3）

脚本：`scripts/gen_mp_demos_rebot.py`。状态：草稿，CPU 上规划已验证，GPU 上未跑通完整 episode。

## 依赖
- `mani_skill==3.0.1`、`mplib==0.1.1`、**`numpy<2`**（numpy 2.x 下 mplib 0.1.1 加载任何 URDF 都会 segfault，实测 1.26.4 可用）
- 规划专用模型：`sim/maniskill_rebot/plan/`（只含碰撞几何 + `.convex.stl` 凸包 + SRDF），推包必须带整个目录

## 录制口径
- 20 Hz，每控制步一帧 wrist + overhead；action 7 维 = 关节1–6 绝对弧度 + `finger_left`（m）
- 抓取朝向固定竖直朝下 `[0.7071,0,0.7071,0]`（wxyz）；就绪姿态是前倾的，不用它的朝向
- 只把 `evaluate()["success"]` 为真的 episode 存成训练数据 `episode_*.npz`
- 示范 seed 必须 < 10000（B0 测试 seed 从 10000 起），越界直接拒绝

## 诊断数据（不进训练集，出问题时复盘用）
| 文件 | 内容 | 用来查什么 |
|---|---|---|
| `run_manifest.json` | 参数、Python/numpy/mani_skill/sapien/mplib/torch 版本、GPU 名、git commit | 环境不一致、版本问题 |
| `plans_<tag>.json` | 每次规划的目标位姿、起点 qpos、状态、轨迹点数、耗时；失败时附异常 | IK 失败、规划超时、目标不可达 |
| `diag_<tag>.npz` → `values` | 每步 `lift_height, is_grasped, contact_force_left/right, hold_count, success` | 抬升阈值与保持步数标定、夹持是否稳 |
| `diag_<tag>.npz` → `track` | 每步实际 qpos(8) + 前 7 维与目标 action 的误差 | PD 增益不足、跟踪滞后、夹爪没合上 |
| `diag_<tag>.npz` → `*_first/_last` | 首末帧 wrist/overhead 图 | 遮挡、方块出画、姿态异常 |
| `meta.json` | 成功 / 规划失败 / 未成功 计数 | 整批成功率 |

`<tag>` 取值：成功为 `00000`，规划失败为 `fail_plan_00000`，执行完未成功为 `fail_success_00000`。三种情况都会落盘。
