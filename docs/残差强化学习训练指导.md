# OpenArm v1 + 冻结 SmolVLA：Residual PPO 训练指导与开源方案汇总

> **文档定位**：可操作工程指南 + 开源方案对比。先训残差、后做完整对照。  
> **撰写日期**：2026-10-12（Asia/Shanghai）  
> **诚实声明**：文中凡标注「已亲自打开核实」者，均通过 GitHub API / 仓库 README / arXiv HTML 页面核对；标注「未亲自打开源码细节」或「论文级参考」者，仅作设计借鉴，勿当作可直接复用代码。

## 1. 目标与范围

### 1.1 项目目标

| 项 | 约定 |
|---|---|
| 机器人 | OpenArm **v1 单臂** |
| 仿真 | `enactic/openarm_mujoco`（MJCF 资产） |
| Base policy | **已微调并冻结**的 SmolVLA（LeRobot） |
| 学习对象 | Residual PPO，只学对 **关节位置目标** 的有界修正 |
| 任务 | 抓取方块并 **稳定抬升**（终局高度门限 + 保持） |
| Actor 观测建议 | `[q, qdot, a_base, phase]` |
| 残差幅度建议 | 关节约 **±0.03 rad**（可按关节单独放宽夹爪） |
| 硬约束 | **禁止**方块位姿等特权状态进入 Actor |


### 1.1.1 团队已对齐的契约（2026-10-12 群聊，已冻结进文档）

- 第一版 Actor 观测：`[q, qdot, a_base[t], phase/chunk_idx]`，**不接** VLA embedding。
- `a_exec = clip(a_base + δ)`，且提供 **δ=0 ≡ base** 单测；残差只加在**控制步**。
- 无相机 Env：只做接口/零残差冒烟，**不当**正式视觉闭环或正式 residual 评测。
- 动作 8 维与冻结 SmolVLA 同空间；chunk 默认 H≈50，逐步读 `a_base[t]`。
- **归一化**：冒烟用物理单位；接真 SmolVLA 后反归一化只认**单臂** MEAN_STD（禁止公开双臂统计），并写入配置版本 + `obs_keys_hash`。
- **残差 bound**：臂关节可调度 `clip_c ∈ {0.03, 0.05, 0.10}` rad（默认 0.03）；夹爪 **slide（米）** 与臂（rad）**分维** bound，映射表定死，禁止 silent broadcast。
- **日志最小字段**：`phase, chunk_idx, a_base, delta, a_exec, seed, obs_keys_hash, reward_version, clip_c, chunk_refresh, chunk_stale`（刷新时刻与超时作废须显式打点）。
- **本地门禁骨架**：`/workspace/openarm_residual_gate/`（`python3 test_zero_residual_gate.py`；契约见同目录 `contract.json`）。下一步：stub `_physics_step` → 真 `v1/openarm.xml`。

### 1.1.2 Env 就绪门禁（六条全过才允许极短 smoke）

1. δ=0 ≡ base（动作级）
2. chunk 逐步对齐（`a_base=chunk[phase]`，超时作废并刷新）
3. 特权隔离（方块位姿等不得进 Actor）
4. reward v0 落盘可复现（含 `reward_version`）
5. B0（零残差）评测结果落盘
6. 安全层：关节限位 + 分维 clip

**未过门禁前禁止**安排 3e5～1e6 长时间训练；用户点头前只允许极短 smoke。

### 1.2 「先训残差」意味着什么

在完整对照（VLA-only / 零残差 / 随机残差 / Residual PPO）之前，先把下列工程链路跑通：

1. **可 reset / step 的 ResidualEnv**（哪怕 base 先用假策略）；
2. **零残差门禁**：残差网络输出恒为 0 时，行为与纯 base 在动作层面逐点一致；
3. **有界残差 + PPO.learn** 能完成至少一次短跑（smoke）；
4. 再接真实冻结 SmolVLA chunk，再补对照实验。

**不要**一上来就对标 SO-100 仓库的成功率数字，也不要同时改奖励、观测维、残差 bound 和 VLA checkpoint。

### 1.3 前置假设（必须满足，否则先补）

- [ ] 已有可用的 OpenArm v1 单臂 MuJoCo 场景（可从 `v1/openarm.xml` 派生，并自行加桌面、方块、相机）。
- [ ] 已有微调后的 SmolVLA checkpoint，且 **闭环**已验证「能大致对准方块」（不必很高成功率，但不能是纯轨迹记忆）。
- [ ] 动作语义与 VLA 输出一致：建议统一为 **绝对关节位置目标（rad）+ 夹爪**，控制频率固定（如 20 Hz）。
- [ ] 公开 `openarm_mujoco` **无**现成 ResidualEnv、**无**抓取任务 Gym 封装——必须自建（见 §4）。
- [ ] v1 默认 MJCF **未配置任务相机**（`v1/scene.xml` 仅地面与灯光；`v1/openarm.xml` 为 7 臂关节 + 1 指关节执行器）。VLA 需要图像时，须在场景中 **自行添加** top/wrist 相机。

### 1.4 范围外（本文不覆盖）

- 真实 OpenArm 上的 online RL / HIL-SERL
- Sim-to-real 潜空间对齐（VLaRL 思路，留待后续里程碑）
- 解冻 VLA 做 full fine-tune 或 Flow-SDE GRPO
- 伪造或搬用其他仓库的成功率数字

## 3. 推荐技术路线（针对 OpenArm）

### 3.1 最小可训（建议 1–2 周内打通）

目标：证明「残差 PPO 能在 OpenArm 上稳定更新，且零残差 ≡ base」。

```text
假 base 或已冻结 SmolVLA
        │
        ▼
OpenArm ResidualEnv（自建）
  obs = [q, qdot, a_base, phase]
  act = Δq ∈ [-0.03, 0.03]^n  (夹爪可单独 bound)
  a_exec = clip(a_base + Δq, ctrlrange)
        │
        ▼
零残差门禁（动作级逐点一致）
        │
        ▼
PPO.learn（SB3 或 mothinf 风格自研）smoke → 短训
        │
        ▼
日志：成功率、|Δ|、bound-hit、ctrl clip、KL
```

**优先复用**：

1. **mothinf/vla-residual-rl** 的契约与门禁（观测顺序、零初始化、phase、step0 gate）。
2. **SB3 PPO + Gymnasium** 作为训练脚手架（若不想维护自研 PPO）。

### 3.2 完整对照（残差跑通后）

| 条件 | 定义 | 用途 |
|---|---|---|
| VLA-only | 只用冻结 SmolVLA chunk，不加残差 | 上限/基线 |
| 零残差 | ResidualEnv 强制 Δ=0（或 actor 权重保持全零且确定性） | 接口正确性 |
| 随机残差 | Δ ~ Uniform(bound) 或策略先验噪声 | 排除「随便抖也能涨分」 |
| Residual PPO | 学习有界 Δ | 主方法 |

评测协议建议提前冻结：固定方块 XY 集合、固定 action seed、成功定义（终局抬升高度 + 可选 ever-lift）、禁止用训练中的 online 成功率写论文结论。

### 3.3 为什么不优先 RLT / EXPO / VLaRL

| 路线 | 何时再考虑 |
|---|---|
| RLT（vla-rlt / RL-Token-SmolVLA） | 已上真机、需要隐状态 token 与人工干预时 |
| TinyVLA EXPO/DSRL | 想在 LIBERO 上对比 edit/noise 接口时 |
| VLaRL | 仿真残差要部署真机且愿做 latent mapper 时（当前无开源实现） |

当前用户明确「先训残差」→ **mothinf 式 proprio + a_base + phase + PPO** 最贴合。

## 4. 环境与接口清单

### 4.1 公开资产：可直接复用 vs 必须自建

| 组件 | 状态 | 说明 |
|---|---|---|
| `v1/openarm.xml` 单臂 MJCF | **可直接复用** | 7 个 hinge + 1 个 finger 滑动执行器；`home` keyframe |
| `v1/scene.xml` | **部分复用** | 默认 include **双臂** `openarm_bimanual.xml`；单臂需改 include 或自建 scene |
| 桌面 / 方块 / 目标区域 | **必须自建** | 公开仓无抓取任务 geom |
| top / wrist 相机 | **必须自建** | v1 默认无任务相机；SmolVLA 需要图像则自行加 `<camera>` 并用 `mujoco.Renderer` |
| Gym/Gymnasium ResidualEnv | **必须自建** | 不存在 |
| 冻结 SmolVLA 推理封装 | **参考 mothinf / LeRobot** | `SmolVLAPolicy.from_pretrained` + processor；chunk 对齐自写 |
| Residual PPO 训练循环 | **参考 mothinf 或 SB3** | 见 §5 |

### 4.2 ResidualEnv 契约（建议冻结成 JSON）

```text
observation (Actor，禁止特权):
  q      : (n,)  执行器/关节位置 [rad 或与 VLA 一致的单位]
  qdot   : (n,)  速度
  a_base : (n,)  当前时刻 base 动作（chunk 内当前步）
  phase  : (1,)  chunk 内相位，建议 phase = i / (chunk_size - 1) ∈ [0,1]

action:
  Δ      : (n,)  tanh-squash 后乘 per-joint bound
  建议 bound ≈ ±0.03 rad（臂）；夹爪可 ±0.05～0.10（单位与执行器一致）

execution:
  a_exec = clip(a_base + Δ, actuator_ctrlrange)
  以固定控制频率子步 mj_step

info（可含特权，仅日志/Critic，禁止进 Actor）:
  cube_xyz, success, clipped_count, |Δ|, base_action, ...
```

OpenArm v1 单臂：`n = 8`（7 arm + 1 finger）时，观测维约为 `8+8+8+1 = 25`。若 VLA 输出维与执行器维不一致，必须在契约中写明映射，禁止 silent broadcast。

### 4.3 零残差门禁（硬门禁，建议自动化）

在接入 PPO 前，对同一 reset seed / 同一 VLA action seed：

1. **动作级**：初始化 actor 最后一层 weight/bias = 0 → 确定性前向 `Δ ≡ 0` → `a_exec` 与 VLA-only **逐元素相等**（允许仅 float 误差）。
2. **行为级（宽松）**：零残差成功率与 VLA-only 的差落在预注册容差内（参考 mothinf step0_gate：不要要求随机接触任务「成功率绝对相等」）。
3. **失败即停**：任一 mismatch → 禁止开训。

### 4.4 Base policy 接口

```text
每 chunk_size 步（如 50）调用一次冻结 SmolVLA：
  images (自建相机) + language + state → action chunk (T, n)
每控步取出 a_base = chunk[phase]
phase++；若 phase==T 则刷新 chunk
```

训练残差时 **VLA 全程 eval + requires_grad=False**。

## 5. 逐步操作指南

下列命令为 **示意脚手架**（路径按你的仓库调整）。不假设你已 fork mothinf。

### 5.0 依赖建议

```bash
# 示例环境（版本按你现有 SmolVLA 栈锁定）
python -m venv .venv && source .venv/bin/activate
pip install mujoco gymnasium stable-baselines3 torch
pip install "lerobot[smolvla]"   # 或与现有微调环境一致
pip install openarm-mujoco      # 或 git clone enactic/openarm_mujoco
export MUJOCO_GL=egl            # 无头服务器
```

### 5.1 步骤 A：单臂场景最小可动

1. 从 `v1/openarm.xml` 建 `scenes/openarm_v1_lift_cube.xml`：桌面、方块 free joint、可选 barrier。
2. 添加相机，例如：

```xml
<camera name="top" pos="0.4 0 0.8" xyaxes="0 -1 0 0.5 0 1"/>
<camera name="wrist" pos="0 0 0.05" xyaxes="0 -1 0 1 0 0"/>  <!-- 挂到 hand body 下 -->
```

### 5.3 步骤 C：实现 ResidualEnv（Gymnasium）

```python
import gymnasium as gym
from gymnasium import spaces
import numpy as np

class OpenArmResidualEnv(gym.Env):
    metadata = {"render_modes": []}

    def __init__(self, base_policy, bound=0.03, chunk_size=50, control_hz=20):
        self.base = base_policy
        self.bound = np.full(self.n, bound, dtype=np.float32)
        # 夹爪可单独：self.bound[-1] = 0.05
        self.chunk_size = chunk_size
        obs_dim = self.n * 3 + 1
        self.observation_space = spaces.Box(-np.inf, np.inf, shape=(obs_dim,), dtype=np.float32)
        self.action_space = spaces.Box(-1.0, 1.0, shape=(self.n,), dtype=np.float32)
        # ... 加载 MjModel/MjData、方块、相机 ...

    def _obs(self):
        phase = np.float32(self.phase / max(self.chunk_size - 1, 1))
        return np.concatenate([self.q, self.qdot, self.a_base, [phase]]).astype(np.float32)

    def reset(self, seed=None, options=None):
        super().reset(seed=seed)
        # keyframe + 随机方块 XY（训练分布）
        self.chunk = self.base.infer_chunk(self._vla_obs())
        self.phase = 0
        self.a_base = self.chunk[0]
        return self._obs(), {}

    def step(self, action):
        # action ∈ [-1,1] → Δ = tanh 已由策略保证或此处 tanh
        delta = np.clip(action, -1, 1) * self.bound
        a_exec = np.clip(self.a_base + delta, self.ctrl_lo, self.ctrl_hi)
        self.data.ctrl[:] = a_exec
        for _ in range(self.substeps):
            mujoco.mj_step(self.model, self.data)
        reward, terminated, info = self._reward_and_done(delta)
        if not terminated:
            self.phase += 1
            if self.phase == self.chunk_size:
                self.chunk = self.base.infer_chunk(self._vla_obs())
                self.phase = 0
            self.a_base = self.chunk[self.phase]
        return self._obs(), reward, terminated, False, info
```

## 6. 奖励、超参、防泄漏与日志

### 6.1 奖励起点（可改，但一次只改一类）

```text
r_t = w_z * cube_z
      - λ * ||Δ||²
      + 1{episode_end and cube_z >= z_success}
```

- **不要**把「末端到方块距离」放进 Actor 可间接利用的通道若你禁止特权；若仅用于 **reward shaping**，需在文档写明「训练用特权奖励，部署不需要」。
- 稀疏成功即可时，可减弱 `w_z`，避免策略只「拱高度」而不抓稳。

### 6.2 防泄漏清单

| 风险 | 规则 |
|---|---|
| 方块位姿进 Actor | 禁止；代码 assert 观测维与字段名 |
| Critic 用特权 | 允许（VLaRL/非对称 AC），但部署 Actor 无特权；本项目最小版可 Actor=Critic 同观测 |
| 评测 pose 进训练 | 冻结 validation / sealed test |
| 用 offline RMSE 选 base | 参考 mothinf：闭环成功率优先 |
| 软件渲染当「看见」 | fail-fast：禁止 llvmpipe 充数（若依赖视觉） |

### 6.3 必打日志

- episode return、success、ever_lift、final_cube_z  
- per-joint mean \|Δ\|、bound-hit fraction、ctrlrange clip count  
- approx KL、clip fraction、value loss、entropy  
- VLA 推理耗时 / chunk 次数（性能）  
- 零残差门禁结果（每次换 base checkpoint 重跑）

## 7. 常见坑

1. **归一化**：`VecNormalize` 对 `phase∈[0,1]` 与已标定关节角混用易破坏尺度；可只归一化 q/qdot，或关闭 obs norm。  
2. **Chunk 对齐**：phase 与 `a_base` 必须来自同一 chunk；刷新 chunk 时勿用过期 a_base。  
3. **动作语义**：相对增量 vs 绝对目标搞混会导致「残差看起来很小、机械臂乱飞」。  
4. **噪声过大**：PPO 探索在 tanh 前；bound 外再靠 clip 会浪费；初始化 log_std 宜偏小（mothinf 用 -2.0）。  
5. **特权泄漏**：reward 里用 cube 可以，但不要把 cube 拼进 obs。  
6. **OpenArm 手指**：finger 是 slide（米），与臂关节 rad 不同——bound 必须分维，禁止统一 ±0.03 rad。  
7. **双臂 scene 误用**：`v1/scene.xml` 默认 bimanual；单臂请改 include。  
8. **无相机却跑视觉 VLA**：必黑图/错图；residual 又看不见视觉 → 整体失败。先加相机或先用假 base。  
9. **成功率数字迁移**：SO-100 的 +11 pp **不是** OpenArm 预期。  
10. **离线变好、闭环变差**：见 soarm101-offline-rl 警示；以闭环门禁为准。
